# Handoff — c4p Games (2026-05-07)

Plan for a Wordle-style daily game system on crazy4points. **No code written yet.** Pick up here in the next session.

## The concept

- Newsletter has a teaser/CTA. User clicks → lands on `/games/[slug]` and plays.
- One puzzle per day per game, deterministic by date (URL-stable, archive works).
- Anonymous play (localStorage for streaks). No login wall.
- Each game produces a copy-paste emoji result string for sharing.
- Six games on rotation, one per day of the week.

## The 6 games

| Day | Game | Mechanic | Build effort |
|---|---|---|---|
| Mon | **Code Crack** | Daily IATA code: type the 3-letter code given the city, OR name the city given the code. Streak-based. | Very low — IATA list is open data |
| Tue | **Routle** | Mystery route. 6 clues drip-fed; guess in fewest clues. Clue order: distance → alliance → hub city → cabin partner → runway count → mile cost. | Low — auto-generates from `programs` + `award_chart` data |
| Wed | **Pyramid** | 6-rung ladder; each rung shows two redemptions, pick the higher-value one to climb. | Medium — needs cents-per-point oracle |
| **Thu** | **Layover** | "You have 3 hours at HKG, where do you go?" 4-5 location cards (lounge / dim sum / shower pod / mall run / quiet zone). Pick one, reveal community % + Jill's pick + one-line reason. | Low — admin writes 1 scenario/day |
| Fri | **Middle Seat** | Drag passengers to airplane seats with constraints: family adjacency, exit-row tall, status-locked, couple together, bag-only aisle preference. Score = (constraints met) − (middle seats used). | Medium-high — drag-drop + constraint checker + SVG seat maps |
| Sat | **Fare Class Decoder** | 5 fare codes shown for one airline; drag to slots: full-Y biz / discount biz / paid F / award F / upgrade-eligible. | Low — JSON per airline |
| Sun | Replay/catch-up | — | — |

Thu is newsletter day → Layover gets the spotlight in the newsletter teaser.

## Killed ideas (don't revisit)

- **Milesdle** — guess mile cost. Too dynamic; award charts shift constantly. Hard to keep seed data accurate.
- **Original Layover** (mystery hub silhouette). Repurposed into airport-spot picker.

## Architecture

- **Hub** at `/games` — grid of 6 cards, today's puzzle highlighted, "coming soon" cards for unbuilt games.
- **Per-game** at `/games/[slug]` — today + yesterday's answer + archive.
- **Daily seed** = puzzle ID derived from `YYYY-MM-DD`. Same date = same puzzle for everyone.
- **Anonymous** — localStorage for streaks/results. (Add accounts later if leaderboards become a thing.)
- **Per-game seed table** (`game_routle_puzzles`, `game_codecrack_puzzles`, etc). Some seeds are admin-written (Layover, Middle Seat scenarios), others auto-generated (Routle, Code Crack pull from existing tables).
- **Shared endpoint** `/api/games/today` returns today's puzzle for each game — newsletter generator reads this for the teaser.

## Middle Seat — detailed spec (building first, ahead of phase order)

User loved this one and wants to build it now, not wait for P4.

### Mechanic
- Small narrow-body seat map (~6 rows × 6 seats, ABC|DEF), some seats pre-blocked.
- 8–12 passengers in a tray, each with constraint chips (adjacency, couple, status-row, exit-row, bulkhead, aisle preference, etc.).
- Drag passengers onto seats (desktop) / tap-to-select (mobile).
- Hard constraints must be met to "submit." Soft preferences are flavor only.
- **Score = how fast you solved it.** Timer starts on first move, pauses on tab-hidden, stops on valid submit. No middle-seat math.

### Tier copy (LOCKED as the idea — exact time thresholds TBD after first 100 plays)

| Rough tier | Emoji + name | Copy |
|---|---|---|
| Fastest | 🥂 **First Class Suite, Arriving Early** | "Lie-flat, caviar service, and a tailwind shaved 40 minutes off the flight. The pilot personally thanks you for flying." |
| Very fast | 🍾 **Business Class Window, Upgrade Cleared** | "You paid economy. Got tapped at the gate. Pajamas in a bag. Champagne before takeoff. This was meant for you." |
| Fast | 💺 **Premium Economy 7A, Empty Middle** | "Extra legroom AND nobody next to you. You spread out like you own the row. You do. You own the row." |
| Solid | 🎒 **Main Cabin Aisle, Exit Row** | "Legs out. Bag at your feet. First off the plane. Solid travel day, no notes." |
| Meh | 🪟 **Window in 24A, Decent Nap** | "Behind the wing. Engine hum. You slept through the snack cart and you don't regret it." |
| Rough | 😬 **Middle Seat by the Galley, Crying Baby** | "Cart hits your elbow every 11 minutes. The baby has been crying since boarding. Your headphones are in your checked bag." |
| Bad | 🚽 **Middle Seat by the Lav, Broken Flush Light** | "It dings. It dings AGAIN. Someone's been in there 22 minutes. You've stopped speculating about why." |
| Disaster | 🧌 **Last Row, Middle, Doesn't Recline, TV Broken, Diverted to Buffalo** | "Bin's full. Ankle in your face. Black screen for six hours. Then a weather diversion. You're sleeping on an airport bench tonight." |

Pattern: **stack three indignities (or three blessings) per tier.** One thing is bad luck; three is a story.
