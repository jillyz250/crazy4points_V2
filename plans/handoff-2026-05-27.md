## Design decisions locked in today (don't re-litigate)

1. **Firecrawl official sources directly, don't ask Jill to paste.** See `~/.claude/.../memory/feedback_firecrawl_official_sources.md`. Established 2026-05-26.
2. **Cite only official + current sources** in migrations, source docs, blog posts. Blogs are fallback when official is silent / 404 / bot-blocked. Same memory file.
3. **Never claim 100% accuracy** from any LLM/scrape combo. Calibrate confidence + hedge editorial language. ~90% confidence with clear sourcing is the right standard for editorial program pages.
4. **Don't hardcode partner counts in program intros** — use `{slug_airline_count}` / `{slug_hotel_count}` / `{slug_partner_count}` tokens that resolve at render time. Expander in `utils/programs/expandIntroTokens.ts`. See `feedback_no_hardcoded_counts_in_intros.md`.
5. **5-tier verification rule** (hardcoded in factcheck-program.mjs when built):
   - T1: 1 official issuer source < 6mo → VERIFIED
   - T2: Official 404/silent + 2+ trusted-blog 2026 sources → VERIFIED (flagged third-party fallback)
   - T3: Only 1 third-party source → NEEDS CLARIFICATION
   - T4: Sources disagree → NEEDS CLARIFICATION (never auto-pick winner)
   - T5: No 2026 source → INCORRECT
6. **Trusted-blog allowlist** (everything else counts as 0 sources):
   TPG, OMAAT, Frequent Miler, AwardWallet, Upgraded Points, View From The Wing, NerdWallet (transfer ratios only), LoyaltyLobby, Doctor of Credit, Milesopedia, AustralianFrequentFlyer, 10xTravel, AwardTravelFinder
7. **Date floors:** 6 months for stable facts, 90 days for volatile (welcome bonuses, transfer bonuses, point values)
8. **Risk levels** (hardcoded criteria):
   - HIGH: affects booking math, money, points, dates, eligibility
   - MEDIUM: affects strategy framing
   - LOW: tone, phrasing, secondary context
