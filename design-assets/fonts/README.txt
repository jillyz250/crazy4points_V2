crazy4points — Royal Glow Font Pack
====================================

Three Google Fonts used across crazy4points.com.
Both .ttf (broad tool support) and .woff2 (web) included.

PLAYFAIR DISPLAY (serif) — display / all headings (h1–h6)
  CSS variable: --font-display
  Weights: 400, 500, 600, 700, 800

LATO (sans-serif) — body copy, paragraphs
  CSS variable: --font-body
  Weights: 300, 400, 700

MONTSERRAT (sans-serif) — UI, nav, buttons, labels
  CSS variable: --font-ui
  Weights: 400, 500, 600, 700
